# From UDM to UCM, and on to a Professional Team

[简体中文](../09-ucm-handover.md) · English

The earlier stories describe how I used UDM to express UI structure, properties, and user intent. For 0.2, I moved that design to JSON-based UCM. Studio kept its established interface and workflows, while the ownership of project structure, property definitions, and defaults became clearer. When the builder generates an app, it selects the parts of Studio’s shared runtime the project uses.

The BMI calculator is a small example, but it helped answer a bigger question: the same project can produce Windows and Android applications. That establishes a path forward for the architecture. The next step calls for professional engineers and testers to exercise it with real applications, different devices, and systematic test coverage.

I’m looking for a company or professional team willing to take over ongoing development. I would like to remain the project lead and architecture designer, working with the team to set priorities, review key design decisions, and guide delivery. The team would lead implementation, systematic testing, cross-platform validation, and release maintenance to turn a working prototype into a dependable product.

I would start with one business scenario and work through design, build, and testing together. Seeing firsthand which design decisions hold up and which need improvement would give us a basis for a long-term handover.
