# UUI Studio 的故事

我是一名牙医，也是 UUI Studio 的构想者和架构设计者。我负责需求、架构规则、方向和实际体验判断，实现代码由 Codex 生成。这些文章记录想法的由来、具体设计选择，以及我们怎样反复尝试和改进。

> AI 能干的事情，我就尽量不插手。这叫各取所长，不否定别人，也不否定自己。

可以按顺序阅读，也可以从感兴趣的问题开始。故事记录开发过程与设计理由；当前公开测试包的能力和验证范围，请看[产品首页](../README.md)、[发行说明](../RELEASE_NOTES.md)和[测试指南](../测试指南.md)。
