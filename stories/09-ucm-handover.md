# 从 UDM 到 UCM，然后交给专业团队

简体中文 · [English](en/09-ucm-handover.md)

前面的故事记录了我怎样用 UDM 表达界面、属性和用户意图。到了 0.2，我把这套思路迁移到 JSON 格式的 UCM。成熟的 Studio 界面和工作流得以延续，工程结构、属性定义和默认值的归属也更清楚了。生成 APP 时，构建器从 Studio 的共享代码中抽取工程用到的部分。

BMI 计算器是个小例子，却帮我验证了一个大问题：同一个工程可以生成 Windows 和 Android 应用。这个结果说明架构可以继续走下去。接下来还需要专业人员用真实业务、不同设备和系统化测试，把工程和使用细节做扎实。

我希望一家有长期投入能力的公司或专业团队接手后续开发。我愿意继续负责架构设计和项目方向，和团队一起确定优先级、审查关键设计并推进交付。团队可以接手工程实现、系统测试、跨平台兼容验证和发布维护，让项目从可运行的原型走向可靠的产品。

我希望先和有意愿的团队一起选一个业务场景，从设计、构建到测试完整走一遍。能共同看清哪些设计值得保留、哪些环节需要改进，才有基础谈长期接手。
