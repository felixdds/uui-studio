# 动画行为

Windows Studio 主窗口采用整窗 zoom in/out，包含标题栏和边框。真实窗口及 WebView 尺寸不变，使用 DWM 实时投影缩放，避免将工作区动画当作整窗动画。开启 0.05→1，关闭 1→0.05，开启 ease-out、关闭 ease-in。速度沿用 Studio 动画设置，禁用或减少动态效果时跳过。

关闭先经过保存与确认，取消不会缩小或退出。Dialog 保持共享 zoom；已有局部 slide/fade 保持各自用途。维护时必须先核对契约与实现、运行检查，再修改；检查并入总契约门禁。原生改动仍须验证实际投影中间尺寸、源窗口不重排、交接与清理，不能只看耗时。
